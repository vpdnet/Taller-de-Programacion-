objetivo del modulo:
*realizar varias tareas al mismo tiempo para llegar a un objetivo en comun 

conceptos importantes a estudiar:
*bloquear/liberar
*compartir recursos, cooperar y coordinarse
*maximizar la concurrencia y ser eficiente

areas:
privada: accede solo un robot
parcialmente compartida: accede algunos robots(no todos)
compartida: acceden todos los robots

*las areas deben ser disjuntas
*se puede asignar un robot a mas de una area(si o si debe estar asignado al menos a una area)
*la esquina inicial de cada robot debe ser diferente
*cuando el trabajo a realizar es diferente debe declararse mas de un tipo robot
*NO se puede saber el orden en que se ejecutan los robots
